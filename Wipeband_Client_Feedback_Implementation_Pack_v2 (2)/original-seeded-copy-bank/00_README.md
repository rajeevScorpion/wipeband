# Wipeband Website Revamp — Copy Pack v1

## Purpose

This folder is the working copy bank for the Wipeband website revamp.

It is designed to support:
- Next.js-first website implementation
- consistent page-by-page copy development
- platform-agnostic design-system implementation
- clearly labeled image placeholders until final assets are produced separately
- future campaign landing pages
- later WordPress / Elementor adaptation if required
- AI-coder handoff and implementation

## Core commercial decision

Wipeband.com is the primary purchase and customer-relationship channel.

Amazon remains available as a secondary purchase option for customers who prefer it, but Amazon should not receive equal visual emphasis beside the main direct-purchase CTA.

## Core brand communication principle

Parents buy Wipeband. Kids use Wipeband.

The website should therefore:
- feel warm and playful enough for a child-oriented product
- feel credible, clean and engineered enough for an adult buyer
- avoid exaggerated medical or illness-prevention claims
- explain the product in seconds, not paragraphs
- use product utility and everyday convenience as the primary benefit story

## Working tone

Simple. Warm. Practical. Confident. Parent-facing.

Preferred vocabulary:
- within reach
- everyday independence
- wearable
- refillable
- less searching
- less mess
- school
- travel
- play
- fresh layer
- real life

Avoid:
- childish overstatement
- clinical or medical-sounding disease claims
- unsupported hygiene or infection-prevention claims
- vague CTAs such as "Learn More" when a more specific action is possible

## Signature language

**No more messy sleeves.**

**Wear it. Wipe it. Tear it.**

**Designed for kids. Built for real life.**

**Keep the band. Refresh the tissues.**

## Final validation required before publication

Do not publish unverified values for:
- validated age range
- patent status / patent number
- exact starter-kit contents
- exact family-bundle contents
- refill pack count
- pricing
- shipping thresholds
- returns window
- cleaning/care instructions
- refill longevity
- subscription availability
- any health / germ-prevention claim

## File status convention

- `WORKING MASTER` = approved direction but still open to refinement
- `FACT CHECK REQUIRED` = structure/copy is usable, but factual values must be confirmed
- `LEGAL REVIEW REQUIRED` = do not publish without owner/legal review

## Visual Asset Workflow

Final visual generation and editing are intentionally separated from this website-structure workflow.

For the Next.js build:
- use clearly labeled image placeholders
- preserve exact intended aspect ratios
- preserve asset filenames/slots
- do not invent or generate final characters or product imagery
- approved assets will replace placeholders later without changing layout

Critical future product-use rule:
when Wipeband is shown being used to wipe a nose, the tissue surface must face and make contact with the nose correctly.
