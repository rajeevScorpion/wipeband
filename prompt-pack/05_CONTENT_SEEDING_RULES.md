## Unresolved facts

Read `20_FACT_CHECKLIST.md`.

Do not guess:
- age
- patent status
- product counts
- price
- shipping threshold
- return period
- cleaning instructions
- subscription availability
- health claims

Implementation should centralize these facts so a later update changes them once.
