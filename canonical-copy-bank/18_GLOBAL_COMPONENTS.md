# Global Elementor Components

**Status:** WORKING MASTER

These components should be created once and reused.

---

## 1. Announcement Bar

Supports:
- brand message
- free-shipping threshold
- seasonal message
- promotional message

---

## 2. Header

Desktop:
- logo
- How It Works
- Shop
- Refills
- Our Story
- FAQ
- Cart
- optional primary Shop Wipeband CTA

Mobile:
- logo
- menu
- cart

Do not place Amazon in primary navigation.

---

## 3. Primary Button

Default label examples:
- Shop Wipeband
- Shop Starter Kit
- Add to Cart
- Shop Refills

---

## 4. Secondary Button

Examples:
- See how it works
- Our story
- View FAQs

---

## 5. Amazon Tertiary Link

Use text-link or low-emphasis outline treatment.

Examples:
- Prefer Amazon? Shop on Amazon →
- Also available on Amazon →
- View on Amazon →

Never match primary CTA emphasis.

---

## 6. Wear / Wipe / Tear Component

### Wear it.

Put Wipeband on like a watch.

### Wipe it.

Use the soft tissue when needed.

### Tear it.

Remove the used layer to reveal the next fresh one.

Use across:
- Home
- How It Works
- Shop
- Product pages
- Campaign landing pages

---
