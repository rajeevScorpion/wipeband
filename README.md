# Wipeband Next.js AI Coder Prompt Pack v1

This is a self-contained handoff package for building the redesigned Wipeband website.

## Start here

Copy the contents of:

`prompt-pack/STARTER_PROMPT.txt`

into your AI coding agent after providing this full folder/repository context.

## Included

- complete canonical copy bank
- design system
- copy style guide
- fact checklist
- route map
- component map
- technical architecture
- content seeding rules
- Stripe commerce scaffold instructions
- SEO metadata
- asset placeholder plan
- acceptance checklist
- structured seed JSON

## Important

Final visual assets are intentionally not part of this package. The build must use replaceable placeholders.

Before public launch, resolve the open items in:
`canonical-copy-bank/20_FACT_CHECKLIST.md`


## Finished build expectation

The AI coder should deliver a complete, high-fidelity, responsive site with:
- all pages populated
- polished image placeholders
- no dark mode
- Framer Motion micro-interactions
- scroll/reveal animation
- route/page transitions
- accessibility-safe reduced-motion behavior

Final image creation happens separately.
